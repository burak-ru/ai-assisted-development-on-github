# AI-Assisted Development on GitHub

### Analyzing AI Contribution Behavior

**Bachelor's thesis (BSc Computing Science)**  
**Author:** Burak Balci  
**Institution:** Radboud University, Nijmegen  
**Date:** March 2026

## Overview

This repository contains my bachelor's thesis on how AI coding agents participate in collaborative software development on GitHub. The study examines AI-authored pull requests, how they are reviewed, how AI contribution patterns change over time, and how they compare with human contributions.

The central research question is: **How are AI-generated contributions integrated and evaluated within collaborative software development workflows on GitHub?**

## Data and methodology

The research uses the **AIDEV dataset**, including pull requests, repository information, reviews, and task-type annotations. I used **Python**, **pandas**, and **Matplotlib** for data cleaning, filtering, aggregation, comparison, and visualization.

The analysis covers:

- AI and human pull-request activity across repositories
- Trends in AI-authored contributions over time
- Human and AI review behavior and review outcomes
- Differences in development task types
- Patterns across different AI coding agents

## Key findings

- AI-authored pull requests became more prevalent over the period represented in the dataset, although changes in dataset composition must be considered.
- AI systems primarily appeared as contributors of proposed code changes; review authority and final evaluation remained largely human-driven.
- AI-authored contributions were concentrated in features, bug fixes, and documentation, while human activity was more broadly distributed across development and maintenance tasks.
- Differences in review patterns across the AI coding agents studied were relatively limited.

These findings describe the repositories and observations represented in the dataset, not necessarily all activity on GitHub.
